`test/planner-fixtures.ts` independently transcribes each phase's named species from the captured domain audit. `test/oak.test.ts` verifies all eight checkpoints and substitutes an unrelated species for every required entry while retaining the same total. It also verifies starter, fossil, Dojo and Eevee alternatives, distinct Moon Stone groups, badge order (Badges V–VII order-free after Erika and Articuno, Giovanni last; `test/guide-alignment.test.ts`), party caps and Set mode. Boxed grinders do not need to be in the legal battle party. Registration remains sufficient for historical Dex entries even if their held instances have been traded away.

All 124 Oak species/group knowledge records (excluding the eight gym badges and Champion) have been promoted to `validated` with these explicit limits in their validation evidence. A separate audit read raw pinned ASM without the extractor or acquisition selector: 147 branch-inclusive roots and 252 recursive paths matched across 40 source files. It checked the Red branch of wild tables, area-specific Super Rod groups, Good Rod pairs, evolution level/item tuples, used NPC trade rows, gift scripts and static object levels. The phase fixtures plus existing phase eligibility checks verify access timing. This validates factual methods and intended groups, not historical execution or the achievement runtime.

The source audit repaired two provenance defects: the Route 4 seller is implemented in `scripts/MtMoonPokecenter.asm` (`lb bc, MAGIKARP, 5`, `EVENT_BOUGHT_MAGIKARP`); Eevee is given inside `scripts/CeladonMansionRoofHouse.asm` (`lb bc, EEVEE, 25`), rather than the roof sign script. The generator and affected generated/curated sources agree. The retained area labels describe their canonical travel destinations. The conditional source-identity regression reads the pinned checkout and verifies all selected source files exist and both gift scripts actually give the intended species.

Current Cave access uses the `TOGGLE_CERULEAN_CAVE_GUY` blocker state. `HallOfFame.asm` hides that object, then clears the Indigo Plateau event range; the transient `EVENT_BEAT_CHAMPION_RIVAL` cannot establish postgame access from a later save. Starter and Lapras receipt use `wStatusFlags4` bits 3 and 0 respectively. NPC trade indices preserve the unused Butterfree row at index 2.

Acquisition readiness means an explainable path can be executed from currently observed prerequisites, including training where instructed. Paths expose missing held donors, finite items, rods, field-move carriers and required retrieval from boxes/daycare. Lower-level source Pokémon can be trained; an unknown daycare current level stays unknown. Resource allocation is greedy in caller target order for unregistered targets; it never promises optimal grinding. The planner does not read continuity baselines, manual history or account awards. Those belong to route integration.

One-time gift/static availability or unobserved purchase funds remain explicit prerequisites, rather than invented evidence. Dex registration alone never confirms gifts/trades or method history. Uninitialized archives remain unknown with their original reason; live box data supersedes the active archived record.

Still open: authenticated decoded Oak badge/Champion trigger behavior; main-set execution audits; supported ROM/core configuration; loaded hardcore subsets; later-state real-save reader fixtures; Safari trigger/session checks; every glitch runtime procedure and award. Synthetic tests and this source audit close none of those gates. Release validation continues to report unvalidated execution records and pending runtime prerequisites.
